# Campus Task Planner

Campus Task Planner는 대학생들이 과제, 시험, 발표, 팀플 일정을 카드 형태로 정리하고 완료 상태를 체크할 수 있는 일정 관리 웹앱입니다.

## 주요 기능

- 과제, 시험, 발표, 팀플 일정 카드 표시
- 전체 일정, 완료 일정, 진행 중 일정, 남은 일정 요약
- 상태 변경 기능: 시작 전 → 진행 중 → 완료
- 상태별 필터 기능
- 완료율 진행 바 표시
- 모바일 화면 대응

## 사용한 도구

- getdesign.md
- Google AI Studio
- GitHub
- Vercel

## 디자인 기준

이 프로젝트는 getdesign.md에서 참고한 Cal.com 스타일의 DESIGN.md를 바탕으로 제작했습니다.  
깔끔한 생산성 도구 느낌을 살리기 위해 단순한 카드 레이아웃, 명확한 버튼, 충분한 여백, 반응형 구조를 사용했습니다.
